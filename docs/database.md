# Diagramas das Tabelas

Esta página reúne os diagramas das tabelas do schema `public` exportados do Supabase. Cada tabela é representada por um diagrama que mostra suas colunas, tipos de dados e chaves primárias/estrangeiras. Esses diagramas são úteis para entender a estrutura do banco de dados e as relações entre as tabelas.

> Observação: Não foi gerado o diagrama do schema completo pois devido a quantidade de tabelas, o diagrama ficaria ilegível. Por isso, cada tabela foi exportada individualmente para melhor visualização.
